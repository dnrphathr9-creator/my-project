ระบบแจ้งซ่อม (HTML + Tailwind + DaisyUI + Node.js + MySQL) ฉบับสำเร็จ

ต้องมี: Docker Desktop และ Node.js ในเครื่อง

วิธีรัน
1. แตกไฟล์ zip ไว้ที่ C:\ จะได้โฟลเดอร์ C:\simple-web
2. เปิด Docker Desktop รอจนมุมซ้ายล่างขึ้น Engine running
3. เปิด VS Code > File > Open Folder > เลือก C:\simple-web
4. เปิด Terminal (เมนู Terminal > New Terminal) แล้วพิมพ์
      docker compose up -d
   รอประมาณ 30 วินาที (ครั้งแรกจะดาวน์โหลด mysql และ phpmyadmin ต้องมีเน็ต)
5. พิมพ์ต่อ
      node server.js
   ต้องขึ้น "เชื่อมต่อฐานข้อมูลสำเร็จ" (ถ้ายังไม่ขึ้น รอ 30 วินาทีแล้วกด Ctrl + C และรันใหม่)
6. เปิด Chrome ไปที่ http://localhost:3000/login.html
      ชื่อผู้ใช้ user1   รหัสผ่าน 1234

ดูฐานข้อมูล: http://localhost:8081 (root / root) เลือกฐานข้อมูล simpledb

หน้าเว็บ (โฟลเดอร์ public)
- login.html   หน้าเข้าสู่ระบบ
- index.html   หน้ารายการ ค้นหา ลบ
- form.html    หน้าแจ้งซ่อม / แก้ไข (form.html?id=เลขรายการ)
- setup.js     ไฟล์กลาง: Tailwind + DaisyUI (ต้องต่อเน็ตตอนเปิดหน้าเว็บ)
- navbar.js    ไฟล์กลาง: แถบด้านบน
- api.js       ไฟล์กลาง: ข้อมูลผู้ใช้ และฟังก์ชันเรียก Backend

หยุดระบบ: กด Ctrl + C ใน Terminal ที่รัน node server.js แล้วพิมพ์ docker compose down
หมายเหตุ: มี node_modules มาให้แล้ว ไม่ต้อง npm install (ถ้าใช้ไม่ได้ ให้ลบโฟลเดอร์ node_modules แล้วสั่ง npm install)
